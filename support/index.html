Частые вопросы

Покупка не открылась

Откройте раздел для взрослых → «Восстановить покупки». Нужен тот же Apple Account, которым платили. Интернет обязателен только для покупки и восстановления; уже купленное работает офлайн.

Пропал доступ после нового iPad

Восстановите покупки в приложении. Рисунки хранятся локально: на новый iPad они сами не переезжают — экспортируйте работы заранее, если они важны.

Ребёнок видит цену?

Нет. Цена и оплата только за родительским шлюзом. На детском пути нет кнопки покупки.

Есть подписка?

Нет. Только разовые покупки без автопродления.
